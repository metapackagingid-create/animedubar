===================================================================
PANDUAN DEPLOY & INSTAL APLIKASI HP PELANGGAN ANIMEDUBAR (PWA + APK)
===================================================================

1. HUBUNGKAN KE BACKEND GOOGLE APPS SCRIPT (OPSIONAL SEBELUM UPLOAD):
   - Buka index.html, cari baris: backendWebAppUrl: ""
   - Tempel URL Web App Google Apps Script Anda (https://script.google.com/macros/s/.../exec)
   - Atau pengguna/admin juga bisa menempelkannya langsung di tab "Saya" dalam aplikasi.

2. HOSTING 100% GRATIS & HTTPS (WAJIB AGAR MUNCUL TOMBOL "INSTAL APLIKASI"):
   Pilih salah satu layanan gratis berikut (drag & drop folder hasil ekstrak ZIP ini):
   - Cloudflare Pages (pages.cloudflare.com) -> Direct Upload -> Upload folder -> langsung dapat link HTTPS.
   - Netlify Drop (app.netlify.com/drop) -> Drag & drop folder -> langsung online HTTPS.
   - GitHub Pages -> Upload ke repository -> aktifkan Pages.

3. PASANG LINK APLIKASI DI WEBSITE BLOGGER:
   - Salin link HTTPS hasil hosting (misal: https://app-animedubar.pages.dev).
   - Buka Website Blogger Anda -> Akses Pemilik / Kelola CMS -> tab "Brand, WA & Harga VIP" ->
     isi kolom "URL Aplikasi HP Pelanggan (PWA/APK)" -> Simpan -> Export XML ke Blogger.

4. CARA PELANGGAN INSTAL DI HP (SEPERTI APK ASLI):
   - Android (Chrome): Buka link aplikasi -> klik tombol "Instal" di banner atas -> aplikasi langsung terpasang di Home Screen tanpa address bar browser.
   - iPhone (Safari): Buka link aplikasi -> ketuk ikon Share (kotak panah atas) -> pilih "Tambahkan ke Layar Utama (Add to Home Screen)".

5. OPSIONAL — BUNGKUS MENJADI FILE .APK ASLI UNTUK DIKIRIM VIA WA / PLAY STORE:
   - Buka https://www.pwabuilder.com
   - Masukkan URL HTTPS aplikasi Anda (misal https://app-animedubar.pages.dev)
   - Klik "Package For Stores" -> pilih Android -> Download file .apk / .aab siap kirim ke pelanggan!
